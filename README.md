# Mini Portofolio - Said Idrus Abdullah

Proyek portofolio pribadi responsif yang dibuat menggunakan HTML, CSS murni, dan JavaScript DOM manipulation.

## Fitur Utama
- Responsif di berbagai ukuran layar (Mobile, Tablet, Desktop)
- Dark Mode / Light Mode Toggle
- Typing Effect pada bagian Hero
- Timeline Academic Background
- Filter Proyek Interaktif
- Fitur Copy Email dengan Toast Notification

## Teknologi yang Digunakan
- HTML5
- CSS3 (Plain CSS / Flexbox / CSS Grid)
- JavaScript (Vanilla DOM Manipulation)
